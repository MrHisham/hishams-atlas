# ATLAS VI — Alpha 2: Personal Quarters & Daily Rhythms

## What is new

- **My Quarters** workspace, accessible from the left navigation
- Personal daily intention and private reflections journal
- Three editable starter routines and the ability to add or remove routines
- Per-day completion checkboxes with progress indicator and daily reset
- Links to the Atlas Life journal and cinematic study room
- Data included in existing local save/backup and restored from older Alpha 1 backups with an automatic default

## Run on Windows

1. Export a full backup from your current Atlas first.
2. Extract this ZIP to a new folder. Do not overwrite your existing install.
3. With Node.js 22.12+ installed, double click `Start Atlas.cmd`.
4. Open the URL shown by the launcher.

The original IndexedDB database name remains unchanged to preserve previous progress **in the same browser and origin**. Browser storage is origin-specific; import your full backup if changing address, port, browser, or device.

## Limitations

This phase adds a *personal quarters workspace* rather than a newly modeled walkable 3D bedroom. Routine reminders are not scheduled and do not run while Atlas is closed. Daily intention and journal entries are persistent notes, not dated journal archives.
