# ATLAS VI — Phase 3: Clinical Hall

Adds four fictional, interactive two-question pharmacy cases: allergy safety, kidney function review, inhaler counseling, and medication reconciliation. Includes case selection, answer feedback, repeat attempts, and persistent completion history.

Clinical practice exercises are educational only; not patient advice or certification. No actual patient data is needed.

Existing IndexedDB name remains unchanged; older Atlas 5 and Atlas 6 backups can load with default empty case history. Export a full backup before upgrading.

Run `Start Atlas.cmd` on Windows or `npm ci && npm run build && npm test` in terminal.
