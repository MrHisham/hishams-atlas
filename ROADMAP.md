# ATLAS Roadmap

## Current: 6.0.0-alpha.6

- Library, medicinal garden, living-routine tools, Clinical Hall, procedural personal spaces
- Day/night lighting and basic room transitions

## Next priorities

1. **Quality gate:** build, unit tests and Windows browser smoke tests; fix errors before release.
2. **Character controller:** playable third-person camera, movement and animations.
3. **Connected spaces:** corridors, scene loading, collision testing and navigation.
4. **Learning depth:** cited, reviewable fictional pharmacy cases and safety checks.
5. **Experience:** accessibility, performance, responsive controls and sound design.
6. **Save compatibility:** export/import tests and explicit migration strategy before changing IndexedDB schema.

Features are intentions, not implemented promises.
